# chainpulse

Мониторинг крипто-инфраструктуры и пульс рынков Polymarket на одной странице. Работает **без сервера и без базы данных**:

- **GitHub Actions** каждые 15 минут проверяет RPC-ноды пяти блокчейнов и API бирж, а также снимает вероятности по самым торгуемым рынкам Polymarket;
- результаты коммитятся в репозиторий: **git и есть база данных**;
- **GitHub Pages** раздаёт статическую страницу с аптаймом, высотой блоков, газом и графиками вероятностей.

Демо с тестовыми данными: открыть страницу с параметром `?demo`.

Интерфейс на 5 языках (English, Русский, Español, 中文, Deutsch): язык определяется по браузеру и переключается в шапке. Тема: светлая, тёмная или как в системе (по умолчанию). Выбор запоминается в браузере. Переводы лежат в `site/i18n.js`, новый язык добавляется копированием блока `en`.

## Вкладка «Infrastructure»

Ethereum, Polygon, Arbitrum, Base и Solana, по два независимых RPC-провайдера на сеть. Плюс API Polymarket, Coinbase, Kraken и CoinGecko.

Главная идея: **нода, которая отвечает 200, ещё не значит здоровая.** Поэтому проверка смотрит на суть:

| Проверка | Что ловит |
|---|---|
| Возраст последнего блока (EVM) | нода отвечает, но застряла на старом блоке |
| Отставание от лучшего провайдера той же сети | нода рассинхронизировалась |
| Слот Solana не растёт между проверками | нода зависла |
| Время ответа > 1500 мс | деградация |
| Ошибка, таймаут, HTTP ≥ 400 | недоступность |

Состояния: 🟢 **up** · 🟡 **degraded** (отвечает, но с проблемой выше) · 🔴 **down**.
Сеть считается упавшей, только если недоступны **все** её провайдеры: именно это почувствовали бы пользователи.

## Вкладка «Markets»

- 8 самых торгуемых долгосрочных рынков Polymarket и история их вероятностей, которую собирает сам проект.
- Самые резкие движения за 24 часа.
- Отсеиваются отдельные спортивные матчи, рынки, которые заканчиваются в ближайшие 2 дня, и почти решённые рынки (< 2% или > 98%). Иначе в топе были бы одни «скачки» от разрешения рынков, а не новости.

Используется только публичное read-only API (`gamma-api.polymarket.com`), без ключей и кошельков. Это не финансовый совет.

## Как это работает

```
┌──────────────────── GitHub Actions (cron */15) ────────────────────┐
│                                                                    │
│  collect job                                 deploy job            │
│  ───────────                                 ──────────            │
│  scripts/infra.mjs    → site/data/infra.json                       │
│  scripts/markets.mjs  → site/data/markets.json   ──►  GitHub Pages │
│  git commit + push                                                 │
└────────────────────────────────────────────────────────────────────┘
                                                        │
                    браузер ◄── site/index.html + app.js читают JSON
```

| Что | Где |
|---|---|
| Сети, провайдеры, пороги, настройки рынков | `config.json` |
| Проверки инфраструктуры | `scripts/infra.mjs` |
| Снимки Polymarket | `scripts/markets.mjs` |
| Пайплайн: сбор → коммит → деплой | `.github/workflows/collect.yml` |
| Фронтенд (чистый HTML/CSS/JS, без фреймворков) | `site/` |
| Генератор демо-данных | `scripts/demo.mjs` |

История хранится 7 дней (672 проверки на провайдера) в компактном формате, чтобы JSON оставался небольшим.

## Запуск локально

Нужен Node.js 18+. Зависимостей нет.

```bash
npm run collect   # проверить сети и снять рынки
npm run demo      # сгенерировать демо-данные
npm start         # http://localhost:8080 (или /?demo)
```

## Деплой на GitHub

1. Создать репозиторий на GitHub и запушить код.
2. **Settings → Pages → Source: GitHub Actions**.
3. **Settings → Actions → General → Workflow permissions: Read and write**.
4. **Actions → Collect & deploy → Run workflow**, чтобы не ждать первого крона.

## Известные ограничения

- Крон GitHub Actions бывает с задержкой 5–20 минут.
- Binance не мониторится: он блокирует запросы с американских серверов GitHub.
- Публичные RPC ограничивают частоту запросов. Раз в 15 минут им это не мешает.
